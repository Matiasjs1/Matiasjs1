## 🚀 What I do

Full stack developer focused on **building and shipping**. I've shipped live games with real daily players, written Solidity smart contracts for an on-chain school-cooperative platform, and built real-time multiplayer, reservation and IoT systems.

- 🎮 **Games:** [Animedle](https://www.animedle.lat) and [AnimeLink](https://www.animelink.lat) are live daily-guessing games (MERN).
- ⛓️ **Blockchain:** `FirstRound` smart contract for [Coppay](https://github.com/coppaykipu/coppay-core), an on-chain platform for school cooperatives (with the ETH Kipu Foundation).
- 🌐 **Web systems:** real-time debate platform, paintball booking, shipping/logistics, AI chat.
- 🔌 **IoT / hardware:** plant-monitoring app with ESP32 + Arduino.

**Currently:** open to work opportunities, freelance projects and collaborations.
